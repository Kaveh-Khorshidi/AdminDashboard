## Installation & Usage
###### Requirements
- Node.js
- npm or yarn

###### Installation Steps
1. Clone the project
```bash
git clone https://github.com/Kaveh-Khorshidi/AdminDashboard.git
```
2. Move into the project directory
```bash
cd my-app
```
3. Install dependencies
```bash
npm install
```

###### Usage Steps
Start the development server
```bash
npm start
```
